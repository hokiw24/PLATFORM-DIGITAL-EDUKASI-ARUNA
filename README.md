# ARUNA - Platform Digital Edukasi Bahari

ARUNA adalah platform berbasis web yang menyajikan edukasi interaktif mengenai ekosistem laut, lingkungan bahari, serta isu pencemaran sampah. Proyek ini dikembangkan sebagai bagian dari inovasi Autonomous Surface Vehicle (ASV) untuk mendukung edukasi publik dan kompetisi riset.

---

## Fitur Utama
* **Interactive Chatbot:** Asisten virtual interaktif untuk merespons pertanyaan seputar ekosistem laut.
* **Berita Bahari Terkini:** Integrasi API berita untuk menyajikan informasi lingkungan maritim secara real-time.
* **Materi Edukasi Visual:** Pembelajaran interaktif mengenai terumbu karang, mangrove, dan pelestarian laut.
* **Mini Game Edukasi:** Media pembelajaran interaktif untuk meningkatkan engagement pengguna.

## Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **API Integration:** GNews API & Chatbot Engine
* **Database:** MySQL
